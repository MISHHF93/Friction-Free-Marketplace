# Infrastructure

Infrastructure and platform engineering assets live here.

- `terraform`: cloud infrastructure modules and environment definitions.
- `kubernetes`: Helm charts, manifests, and GitOps overlays.
- `docker`: local development containers and base images.
- `observability`: dashboards, alerts, SLOs, and telemetry collector configuration.
- `security`: IAM, policy-as-code, signing, scanning, and secret-management configuration.
