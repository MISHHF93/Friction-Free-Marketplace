# Packages

Shared packages used across applications and services.

- `ui`: design system and shared components.
- `config`: shared lint, formatting, TypeScript, test, and build configuration.
- `domain`: shared domain types, value objects, and validation schemas.
- `api-client`: generated API clients.
- `telemetry`: logging, tracing, metrics, and analytics helpers.
- `testkit`: shared fixtures, mocks, contract test helpers, and test utilities.
